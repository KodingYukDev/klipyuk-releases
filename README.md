# KlipYuk! untuk Windows

Editor video tim Creative KodingYuk!, dibantu Kody AI.

**Pasang:** buka [rilis terbaru](../../releases/latest) lalu unduh `KlipYuk-Setup-x.y.z.exe` dan jalankan.
Kalau muncul "Windows protected your PC", klik **More info** lalu **Run anyway**.

Setelah terpasang, KlipYuk! memperbarui dirinya sendiri. Login pakai akun Odoo (khusus departemen Creative).

Repo ini hanya berisi file rilis. Kode sumber privat.
