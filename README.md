# KlipYuk! untuk Windows

Editor video KodingYuk!, dibantu Kody AI. Untuk semua karyawan KodingYuk! dengan akun Odoo.

**Pasang:** buka [rilis terbaru](../../releases/latest), unduh `KlipYuk-Setup-x.y.z.exe`, lalu jalankan.
Kalau muncul "Windows protected your PC", klik **More info** lalu **Run anyway**.

**Syarat:** Windows 10/11 64-bit, ruang kosong di drive C: minimal **2 GB** (unduhan ±330 MB + aplikasi ±1,1 GB + cadangan update).
Kalau installer bilang "internet connection unavailable", biasanya drive C: penuh.

Setelah terpasang, KlipYuk! memperbarui dirinya sendiri. Login pakai email + password Odoo
(yang biasa login lewat Google: buat password dulu lewat "Reset Password" di halaman login Odoo).

Repo ini hanya berisi file rilis. Kode sumber privat.
